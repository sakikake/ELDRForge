ELDR Forge 0.1.0 - macOS Release Notes

Status

Pre-release

Tested Environment and Requirements

- Tested with: Adobe After Effects 2025 (25.6.5)
- Supported After Effects versions: 2025 (25.6.5) or later
- macOS Tahoe 26.6.2
- Apple Silicon or an Intel CPU with AVX2 support
- 16 GB RAM minimum (32 GB recommended for 4K or larger projects)
- Metal or the CPU backend

Initial Release

- 2D fire and smoke fluid simulation using alpha/luma or a point as the source
- Metal backend
- CPU backend

Important Notes

- The binary is not signed with a Developer ID and has not been notarized by Apple.
- macOS may display warnings or prevent the plug-in from loading in some environments.
- This distribution is a pre-release.

File Information

- File name: ELDR Forge.plugin
- Architecture: Universal Binary (x86_64 / arm64)
- Plug-in binary SHA-256: 5accf4710846f7be8de11be7fd8137767544013716b415843c4eafe72f67c5d9
