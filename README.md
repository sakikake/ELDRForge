# ELDR Forge

**ELDR Forge**は、趣味で作成したAdobe After Effects向けの炎・煙2D流体シミュレーションエフェクトです。
入力レイヤーのアルファ/輝度またはポイントを発生源として、炎と煙を生成します。

**ELDR Forge** is a 2D fire and smoke fluid-simulation effect for Adobe After Effects, created as a hobby project.
It generates fire and smoke from an input layer's alpha/luma channel or from a point source.

## リリース情報 / Release Information

macOS版とWindows版の`0.1.0`をPre-releaseとして公開しています。

Version `0.1.0` for macOS and Windows is available as a pre-release.

## 動作確認環境 / Tested Environment

- After Effects CC2025（25.6.5）
- macOS: macOS Tahoe 26.6.2
- Windows: Windows 11 25H2

Tested with After Effects 2025 (25.6.5) on macOS Tahoe 26.6.2 and Windows 11 25H2.

## 動作要件 / System Requirements

- 対応するAfter Effects: 2025（25.6.5）以降
- メモリ: 16 GB以上（4K以上は32 GB推奨）
- macOS CPU: Apple Silicon、またはAVX2対応のIntel CPU
- Windows CPU: Intel第6世代以降、またはAMD Ryzen 1000シリーズ以降のAVX2対応CPU（x64）

- Supported After Effects versions: 2025 (25.6.5) or later
- Memory: 16 GB RAM minimum (32 GB recommended for 4K or larger projects)
- macOS CPU: Apple Silicon or an Intel CPU with AVX2 support
- Windows CPU: An AVX2-capable x64 CPU from Intel (6th generation or later) or AMD (Ryzen 1000 series or later)
