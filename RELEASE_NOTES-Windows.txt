ELDR Forge 0.1.0 - Windows Release Notes

Status

Pre-release

Tested Environment and Requirements

- Tested with: Adobe After Effects 2025 (25.6.5)
- Supported After Effects versions: 2025 (25.6.5) or later
- Windows 11 25H2
- Windows x64 CPU with AVX2 support
- 16 GB RAM minimum (32 GB recommended for 4K or larger projects)
- DirectX 12 or the CPU backend
- Microsoft Visual C++ 2015-2022 Redistributable (x64)

Initial Release

- 2D fire and smoke fluid simulation using alpha/luma or a point as the source
- DirectX 12 backend
- CPU backend

Important Notes

- The binary is not code-signed.
- The operating system or security software may display a warning or prevent the plug-in from loading in some environments.
- This distribution is a pre-release.

- File name: ELDR Forge.aex
- Architecture: x64 (PE32+)
